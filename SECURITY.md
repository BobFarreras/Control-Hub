# Security Policy

## Reporting

No publiquis vulnerabilitats, credencials o dades sensibles en issues.

Utilitza un private vulnerability report a GitHub Security Advisories:

`https://github.com/BobFarreras/Control-Hub/security/advisories/new`

Inclou component i versio afectats, precondicions, impacte, passos de reproduccio i una prova de concepte minima.

## Supported versions

Abans de la primera release no existeixen versions suportades. La politica prevista es mantenir l'ultima versio estable i una finestra de migracio documentada per la versio anterior.

## Secrets

Si una credencial arriba al repositori, s'ha de revocar immediatament. Eliminar-la de Git no substitueix la rotacio. No adjuntar dades reals de clients als reports.
